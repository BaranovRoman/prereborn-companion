# PUBG

## 0.1.1 — 2026-10-21 — Исправлено сохранение игрока

### Исправления
- На вкладке «Игрок» кнопка «Сохранить» ничего не сохраняла. Теперь ник и платформа сохраняются по кнопке и по Enter, а если сохранить не удалось, показывается причина.
- Ошибка сохранения настроек OBS-виджета теперь видна, а переключатель возвращается к сохранённому значению.

## 0.1.0 — 2026-10-21 — Первый выпуск

### Новое
- История матчей PUBG за последние 14 дней: карта, место, убийства и урон. Данные приходят из официального PUBG API через сервер Prereborn.
- Сессия начинается при включении плагина, а с «Запускать вместе с Companion» — при каждом запуске приложения. Матчи текущей сессии отмечены.
- Необязательный OBS-виджет с матчами сессии: добавьте его в OBS как Browser Source по адресу из плагина. Настраиваются число матчей, масштаб, прозрачность фона и заголовки.

### Что сделать после обновления
- Укажите ник и платформу на вкладке «Игрок». Новый матч появляется через несколько минут после окончания — так работает PUBG API.
